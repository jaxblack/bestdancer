# 本周热舞 · 全局变量与栏目设定

> 所有 prompt 通过 `{变量名}` 引用本文件。改栏目风格时，只改这里，其它 prompt 不动。

## 栏目定位

- **栏目名**：本周热舞（Weekly Hot Dance）
- **定位**：面向**跳舞初学者**的**热舞推荐 + 教学向解说**，不是搬运合集。
- **每期结构**：片头 → TOP5 热舞（每支含教学解说 + 难度星级）→ 经典回归（1 支旧舞）→ 片尾。

## 锁定变量

| 变量 | 值 | 说明 |
|---|---|---|
| `{PLATFORMS}` | 抖音、小红书 | 首发双平台 |
| `{ASPECT}` | 9:16 竖屏 | 两平台通用 |
| `{VOICE}` | 年轻女声，活力亲切 | TTS 音色 |
| `{TOP_N}` | 5 | 本周新舞数量 |
| `{CLASSIC_N}` | 1 | 经典回归旧舞数量 |
| `{AUDIENCE}` | 跳舞初学者 | 解说口吻与难度基准都以此为准 |
| `{LANG}` | 中文 | 输出语言 |
| `{SECONDS_PER_CLIP}` | 15–20 秒 | 单支解说可读完的时长 |
| `{TONE}` | 亲切、清楚、不炫术语 | 教学口吻 |
| `{contact}` | 待定（私信 / 邮箱） | 投稿 / 报名 / 合作 联系方式 |

## 合规红线（每期必须遵守）

- 保留原作者**水印**；简介 / 评论区**署名 + 原视频链接**（占位符 `{credits}`）。
- 定位为**推荐 + 教学解说**（加画外音、动作分解、难度打分），非原样搬运。
- 背景音乐有独立版权且有指纹检测：能替换成可商用曲库就替换，否则接受该片段被平台分成 / 静音。
- 只收录允许二次创作 / 可授权的创作者；收到下架请求立即撤。

## 简介固定尾部（`{FOOTER}`）

每条视频简介（抖音 caption / 小红书 body）末尾统一追加：

> 📮 接收投稿 · 北京随舞宣传报名 · 品牌合作 → 私信 / 邮箱 `{contact}`
> ⚠️ 视频素材来自网络，版权归原作者所有；如有侵权请联系删除。

## 品牌视觉

- `{BRAND}`：霓虹 + 都市夜景 + 动感几何（片头 / 片尾 / 转场 / 经典回归卡统一用这套）。
- **主色板（已定）**：

  | 角色 | 色值 | 用途 |
  |---|---|---|
  | 背景 base | `#0B0B14` | 近黑靛底，衬托霓虹 |
  | 主色 A | `#FF2E9A` | 电光品红，栏目主色 / 标题 |
  | 主色 B | `#16E0FF` | 电光青，副色 / 描边 / 转场 |
  | 强调 | `#FFE14D` | 星级角标、重点数字 |
  | 文字高光 | `#FFFFFF` | 字幕 / 正文 |

- 两个高对比主色（品红 × 青）压在近黑底上；封面字用白 + 品红描边最醒目。

## 个人品牌 / 水印（占位）

> **BestDancer** 是独立个人品牌，自成体系，不与任何参考站点联名 / 杂系。

| 变量 | 占位值 | 说明 |
|---|---|---|
| `{BRAND_NAME}` | BestDancer（最佳舞者） | 独立个人 IP |
| `{LOGO}` | `brand/logo.png` | 圆形头像 logo（个人照裁 1:1 + 金色描边），置于水印 / 片头名字前 |
| `{WATERMARK}` | `[logo] BestDancer` | 每帧右上角持久水印；logo 在前，名字白色半透 |
| `{HANDLE}` | @BestDancer | 各平台统一账号名（占位） |
| `{SLOGAN}` | 每周最火热舞 · 零基础也能跟 | 一句话人设 |

- **水印**：圆形头像 logo + `BestDancer`，固定右上角，半透明不挡舞蹈。
- logo 现由个人照裁剪占位（`pipeline/make_logo.py`）；后续可换真 logo / 卡通形象（见 TODO）。
